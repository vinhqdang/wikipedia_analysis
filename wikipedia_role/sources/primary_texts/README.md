# Primary texts (not stored here)

Copyrighted books and scans are kept out of this repository. Put local copies in this folder for your own use: `*.pdf`, `*.epub` and `*.djvu` here are ignored by git (see the repository `.gitignore`).

What has been read from primary texts, with locators and the exact passages used, is recorded in `../annotated_bibliography/13_primary_texts_read.md`.

Still to obtain (see the same note): Simmons (1979), Klosko (1992), Craig (1990), Bicchieri (2006), Hart (1955), and the Pāli suttas listed in `../annotated_bibliography/14_suttas_to_read.md`.
